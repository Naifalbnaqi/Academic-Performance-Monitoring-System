# Academic Performance Monitoring System

A web-based academic KPI monitoring platform developed as a university graduation project to support academic quality management, performance measurement, gap analysis, corrective actions, evidence tracking, and reporting.

## My Role

**Backend Development & KPI Calculation Engine**

My work focused on backend logic, KPI calculations, database integration, and supporting the workflow between entered performance data, targets, achievement percentages, and KPI status.

> This was a team graduation project. The repository represents the complete system, while the role above describes my primary contribution.

## Key Features

- KPI definition and target management
- Academic performance data entry
- Automatic KPI actual-value calculation
- Achievement percentage calculation
- KPI status tracking
- Gap analysis and root-cause analysis
- Corrective action plans
- Evidence/document uploads
- Role-based access control
- University, college, department, and program hierarchy
- Academic quality review workflows
- PDF reporting
- Dashboard and KPI status visualization

## KPI Workflow

The core workflow follows this process:

**Raw Data → KPI Calculation → Target Comparison → Achievement % → Status → Gap Analysis → Corrective Action**

This allows academic quality teams to move from performance measurement to structured improvement actions within one system.

## Local Development
